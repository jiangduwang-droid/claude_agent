# 代码审查规范

当用户请求代码审查时,按以下维度检查:

## 审查维度
1. **安全性**: SQL注入、XSS、CSRF、SSRF、路径遍历等
2. **性能**: N+1查询、不必要的大字段加载、缺失索引
3. **可维护性**: 代码重复、过长函数、命名清晰度
4. **错误处理**: 异常是否被吞没、错误信息是否友好
5. **并发安全**: 竞态条件、锁粒度、死锁风险

## 审查流程
1. 先通读代码理解意图
2. 按维度逐项检查
3. 记录发现的问题(按严重程度排序)
4. 提供具体的改进建议和代码示例

## 输出格式
```
### 审查结果
- 严重问题: X 个
- 建议改进: X 个

### 问题列表
1. [严重] 问题描述
   建议: 具体改进方案
   代码示例
```
